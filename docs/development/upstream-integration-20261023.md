## 集成时同时处理的差异

- 保留唯一源码目录和规范 Debug 重启流程；构建后检查 DLL 写入时间，避免把旧实例或未更新的输出当作新构建。
- 动画期间延后的层级恢复继续传递 `recoverNativeVisibility`，避免丢失本地恢复语义。
- 已沉底时的跳过判断同时验证真实 Explorer 宿主及全局应用边界，避免错误跳过已漂移的窗口。
- 材质选项测试同步玻璃条目，并保留 Win10 隐藏 Mica 的要求。
- 为会话可用性和显示电源 gate 的组合增加回归覆盖。
- 将作者系统菜单的代理进程识别为自有交互目标，防止外部点击观察把菜单操作当成离开 DeskBox；真正点击桌面仍会清除选择。
- 日历测试显式覆盖周一和周日首日，避免依赖本机文化默认值；源代码契约测试兼容 LF/CRLF，并按最终策略检查恢复参数和指针抑制。
